# 词斩

面向考研易错词的离线优先 PWA。应用内置用户提供的 1800 词静态词库，运行时不调用 AI，也不需要密钥或付费接口。

## 功能

- 阅读词 / 写作词双轨掌握：阅读词免强制默写，写作词要求主动提取与拼写
- 识义题先选择“想好了”或“不认识”，确认后才展示六个选项，减少排除法造成的虚假掌握
- 首页“今日主线”把到期复习与剩余新词合成一轮，一键学完；验收、弱点均为自由加练
- 错答或“不认识”后，在醒目释义下显示该词专属的词形、真实语境或释义记忆钩子；1800 词全部预生成、离线可用
- 识义、主动回忆、真实语境、拼写、易混辨析自适应训练；1800 词均内置英文释义，1432 词带真实用例
- 新词全部安排隔题强化：阅读词至少覆盖识义与语境，写作词再增加主动提取或拼写，不再只强化队列前几个词
- FSRS 思路的本地动态调度：同时记录难度、记忆稳定期、预计保持率、实际延迟、近期错误与回答速度
- 易混关系同时来自预设词组与用户真实错选，错选 A 为 B 后会建立双向追杀关系
- 每日词量不设人为上限，首页同步显示今日目标与今日已学
- 识义题切换单词时自动播放英音；回忆、拼写和语境题保持静音，避免泄题
- 当天错误自动重新插入但不增加主线单词总数；主线与专项各自拥有独立恢复槽，重开 App 后原位继续
- 记忆证据展示最近七天学习词量、时间、正确率、预计保持率、24 小时复习压力与高风险词
- 今日歼灭、5 分钟弱点、专项测试、Boss Rush
- IndexedDB 本地持久化、浏览器持久存储申请与应急恢复镜像；JSON 备份同时包含主线和专项会话
- 仅英文单词使用考试试卷式衬线印刷体，其他界面文字保持清晰的系统无衬线体
- Service Worker 完整离线缓存；有道发音按实际使用逐词缓存，断网时优先使用已缓存音频并回退设备英文语音
- 从 Chrome 原生入口安装后以 fullscreen 启动，并在用户首次操作时请求隐藏系统栏

## 部署

仓库根目录即为静态站点，可直接导入 Vercel，无需构建命令。

发布前可运行 `node scripts/validate-project.js`，检查 1800 词、记忆钩子、真实语境、易混关系、PWA 图标与离线核心资源是否完整。
