# 词斩

面向考研易错词的离线优先 PWA。应用内置用户提供的 1800 词静态词库，运行时不调用任何 AI 或第三方 API。

## 功能

- 阅读词 / 写作词双轨掌握：阅读词免强制默写，写作词要求主动提取与拼写
- 六选一与“确实不认识”，减少排除法和猜测造成的虚假掌握
- 固定剧情式语言冒险：三章可玩内容、90 个核心词、物品与情境选择
- 12 篇章 / 60 章节 / 1800 词固定登场与跨章重现规划
- 识义、主动回忆、语境、拼写、易混辨析自适应训练
- 每日词量不设人为上限，首页同步显示今日目标与今日已学
- 当天错误自动重新插入，长期复习到期调度
- 掌握状态、答题速度、遗忘与复活记录
- 今日歼灭、5 分钟弱点、专项测试、Boss Rush
- IndexedDB 本地持久化，JSON 进度导入导出
- Service Worker 完整离线缓存，可从 Chrome 安装为本地 App

## 部署

仓库根目录即为静态站点，可直接导入 Vercel，无需构建命令。
