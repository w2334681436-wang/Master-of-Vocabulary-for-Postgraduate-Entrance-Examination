# 词斩

面向考研易错词的离线优先 PWA。应用内置用户提供的 1800 词静态词库，运行时不调用 AI，也不需要密钥或付费接口。

## 功能

- 阅读词 / 写作词双轨掌握：阅读词免强制默写，写作词要求主动提取与拼写
- 六选一与“确实不认识”，减少排除法和猜测造成的虚假掌握
- 首页“今日主线”把到期复习与剩余新词合成一轮，一键学完；冒险、验收、弱点均为自由加练
- 全屏中文小说式冒险：12 篇 / 60 章 / 360 个主线场景 / 120 条支线 / 600 个可交互场景
- 小说正文仅目标词使用英文，问题统一放在每节末尾；中文翻译按熟练度逐次淡出并可点回查看
- 1800 词固定登场、情境强化、延迟复现、跨篇回归与宿敌验证
- 识义、主动回忆、语境、拼写、易混辨析自适应训练
- 每日词量不设人为上限，首页同步显示今日目标与今日已学
- 识义题切换单词时自动播放英音；回忆、拼写和语境题保持静音，避免泄题
- 当天错误自动重新插入，长期复习到期调度
- 掌握状态、答题速度、遗忘与复活记录
- 今日歼灭、5 分钟弱点、专项测试、Boss Rush
- IndexedDB 本地持久化，JSON 进度导入导出
- Service Worker 完整离线缓存，可从 Chrome 安装为全屏本地 App；在线发音不可用时退回设备英文语音

## 部署

仓库根目录即为静态站点，可直接导入 Vercel，无需构建命令。
