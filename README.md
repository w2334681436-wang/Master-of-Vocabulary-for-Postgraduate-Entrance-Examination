# 词斩

面向考研易错词的离线优先 PWA。应用内置用户提供的 1800 词静态词库，运行时不调用 AI，也不需要密钥或付费接口。

## 功能

- 阅读词 / 写作词双轨掌握：阅读词免强制默写，写作词要求主动提取与拼写
- 识义题先选择“想好了”或“不认识”，确认后才展示六个选项，减少排除法造成的虚假掌握
- 首页“今日主线”把到期复习与剩余新词合成一轮，一键学完；验收、弱点均为自由加练
- 错答或“不认识”后，在醒目释义下显示该词专属的词形记忆钩子；1800 词全部预生成、离线可用
- 识义、主动回忆、语境、拼写、易混辨析自适应训练
- 每日词量不设人为上限，首页同步显示今日目标与今日已学
- 识义题切换单词时自动播放英音；回忆、拼写和语境题保持静音，避免泄题
- 当天错误自动重新插入但不增加主线总数；学习队列可暂停并在重开 App 后原位恢复
- 记忆证据展示最近七天每天的学习词量、有效学习时间、作答次数与正确率，并细分今日掌握状态
- 今日歼灭、5 分钟弱点、专项测试、Boss Rush
- IndexedDB 本地持久化，JSON 进度导入导出
- 考试试卷式宋体 / 衬线印刷风格
- Service Worker 完整离线缓存；从 Chrome 原生入口安装后以 fullscreen 启动，并在用户首次操作时请求隐藏系统栏；在线发音不可用时退回设备英文语音

## 部署

仓库根目录即为静态站点，可直接导入 Vercel，无需构建命令。
